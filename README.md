
# pray-and-sort

## What's Bogosort?

Bogosort is a sorting algorithm that repeatedly shuffles an array until it accidentally becomes sorted.

Unlike other sorting algorithms that use logic, strategy, or basic common sense, Bogosort relies entirely on chance.

Given enough time, it will eventually sort the array.

Probably.

---

## Pseudocode

```text
while array is not sorted
    shuffle array
```

That's it.

There are no hidden optimizations.
There is no secret sauce.
Just vibes and probability.
